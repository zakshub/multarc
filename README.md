# MULTARC

MULTARC is the canonical workspace for an original shared narrative universe designed to grow from anthology comics into interconnected characters, worlds, crossovers, cosmology, and later animated adaptations.

## Core Production Principle

Architecture before manuscript.

## Growth Model

Standalone characters → supporting casts → recurring antagonists → additional protagonists → crossovers → teams → shared locations → organizations → shared history → civilizations → mythology → cosmology → continuity-driven shared universe.

## Format Strategy

The launch format is an anthology comic rather than a single oversized origin story. Individual features may use different genres, tones, and narrative modes while remaining part of one continuity.

## Canonical Repository Areas

- `docs/` — franchise and production architecture
- `canon/` — canon registry, timeline, continuity, narrative debt
- `characters/` — character bibles and consistency specifications
- `worlds/` — locations, dimensions, realms, realities, civilizations
- `issues/` — issue architecture, scripts, page/panel plans
- `production/` — visual DNA, comic specs, animation specs, prompts
- `research/` — source-grounded research and reference notes

## Current Status

Phase: Character 001 development and AI consistency architecture.

## Canon Rule

Nothing becomes canon merely because it was discussed. Canon is established when it is deliberately recorded in this repository.
