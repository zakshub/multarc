# CHR-001 — Expression Sheet Specification v1.0

**Character ID:** CHR-001  
**Name:** Not assigned  
**Canonical Age for this Sheet:** 29–30  
**Purpose:** Lock repeatable facial acting for comic panels and later 2D animation.

## Identity Source

Use the approved launch-age identity direction only.

Do not use the mature 38–40 appearance for this sheet.

## Required Expressions

1. Neutral
2. Focused
3. Skeptical
4. Mildly amused
5. Irritated
6. Angry
7. Suspicious
8. Tired
9. Afraid
10. Shocked
11. Sad / contained grief
12. Emotionally blank

## Required View Consistency

- same head size
- same camera angle
- same lighting
- same background
- same hair and beard state
- same facial proportions
- no costume change
- no age change

## Cartoon Rendering

Original adult 2D science-fiction cartoon.

Use:
- bold readable contour
- simplified facial planes
- clear eye and brow acting
- controlled mouth-shape variation
- restrained cel shading
- production-model-sheet clarity

Avoid:
- photoreal skin
- dramatic cinematic lighting
- painterly rendering
- direct imitation of any existing animated series
- age drift
- hairstyle drift
- beard drift
- changing nose or jaw geometry between expressions

## Acting Rule

Expressions must feel like the same restrained, observant person under different emotional pressure.

Do not over-cartoon every expression.

The stronger expressions should still preserve the character's underlying self-control.

## Approval Gate

This sheet must be approved before final comic-panel generation for Story 01.
