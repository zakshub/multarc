# Character 001 — Age Progression Sheet Specification v0.1

**Character ID:** CHR-001  
**Canonical Name:** Not assigned  
**Purpose:** Lock the same genetic identity across four canonical life stages before comic production.

## Required Age Stages

1. Age 23–25 — youthful / pre-consequence
2. Age 29–31 — primary launch version
3. Age 34–35 — established adult
4. Age 38–40 — mature / future version

## Hard Identity Locks Across All Ages

- same skull proportions
- same eye spacing and core eye shape
- same eyebrow weight and placement
- same nose bridge and projection
- same mouth placement
- same ear placement
- same underlying jaw structure
- same base skin tone
- same recognizable facial asymmetry

## Controlled Age Changes

### Age 23–25
- leanest face
- smoother skin
- fuller youthful hair
- lighter facial hair
- more open posture
- minimal fatigue

### Age 29–31
- primary launch face
- short full beard
- controlled medium-length hair
- lean-medium body
- minimal age lines
- practical dark T-shirt / brown trousers / brown shoes
- rugged square watch introduced as an identity anchor

### Age 34–35
- subtly stronger facial planes
- slightly heavier beard
- more economical posture
- mild under-eye wear
- same wardrobe language, more settled and worn-in

### Age 38–40
- long dark hair with natural grey progression
- full mature beard with natural grey
- visible accumulated fatigue / life history
- permanent mature uniform fully established
- same T-shirt / brown utility trousers / practical shoes / rugged square watch silhouette

## Sheet Layout

Single clean production sheet with four full-body columns and four matching head close-ups:
- identical neutral pose
- identical camera height
- identical focal perspective
- identical lighting
- identical background
- no dramatic scene context
- no props except the canonical watch and permitted minimal accessories

The purpose is comparison, not storytelling.

## Rendering Style

Clearly 2D adult-animation / graphic-cartoon production design:
- confident contour lines
- simplified but recognizable anatomy
- clean shadow shapes
- restrained textures
- repeatable facial construction
- no photorealism
- no live-action rendering
- no direct imitation of any existing animated series

## Approval Gate

This sheet must be approved before:
- final expression library
- action poses
- costume variants
- comic page generation
- animation shot generation
