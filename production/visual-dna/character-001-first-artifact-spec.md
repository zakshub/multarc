# Character 001 — First Artifact Specification v0.1

**Artifact:** Primary Character Reference Sheet — Launch Age  
**Character ID:** CHR-001  
**Target Age:** 29–30  
**Purpose:** Establish the first production-grade visual anchor for future comic and animation consistency.

## Required Views

Single-sheet layout containing:
1. front neutral
2. left profile
3. right profile
4. front 3/4
5. full-body neutral stance
6. head close-up
7. three controlled expressions: neutral, skeptical, focused

## Identity Requirements

Preserve the established photographic identity anchors:
- elongated oval facial foundation
- large expressive eyes
- thick eyebrows
- defined long nose bridge
- lean-to-medium face
- dense dark hair
- controlled short-to-medium beard
- lean-to-medium body frame

## Launch-Age Styling

At 29–30:
- dark dense hair, medium length, controlled but not over-groomed
- short full beard, clearly younger than the age-40 mature version
- no heavy grey
- utilitarian dark charcoal T-shirt
- earthy brown cargo/jogger trousers
- practical brown low-profile shoes
- rugged square mechanical-style watch already present as a continuity anchor
- optional minimal dark bracelet
- no superhero costume
- no tactical armor
- no fashion styling

## Visual Personality

The sheet should communicate:
- observant
- self-contained
- practical
- intelligent
- field-ready
- slightly sleep-deprived
- not glamorous
- not heroic by costume language

## Art Direction

Original adult science-fiction comic character design.

Use:
- clean readable silhouette
- expressive but anatomically grounded facial construction
- controlled stylization
- graphic clarity suitable for repeated comic panels and 2D animation
- neutral studio background for reference utility

Avoid:
- photorealism as final style
- direct imitation of Rick and Morty character anatomy
- direct Marvel costume language
- anime proportions
- exaggerated superhero musculature

## Consistency Rule

This artifact becomes the base visual reference for all launch-age CHR-001 imagery. Later sheets may refine it, but changes to facial structure require explicit revision of the identity bible.
