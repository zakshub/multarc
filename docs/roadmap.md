# MULTARC Roadmap

## Current Position

The franchise architecture is sufficiently defined to begin practical character development.

## Locked Principles

1. Shared universe, not a single isolated title.
2. Anthology-first launch model.
3. Multi-genre franchise: science fiction, adventure, mystery, thriller, conspiracy, horror, fantasy, drama, comedy, satire, crime, and experimental forms may coexist.
4. Marvel is a structural reference for publishing evolution and crossover growth.
5. Rick and Morty is a reference for extreme dimensional imagination and impossible-reality thinking, not a required comedy template.
6. Inside Job is a reference for hidden systems, institutions, conspiracy infrastructure, and worldbuilding.
7. The Narrative Universe Bible governs architecture, character engineering, continuity, adaptation, and expansion.
8. Comic is the canonical launch medium; later animation is an adaptation, not a panel-by-panel conversion.

## Production Sequence

### Phase 0 — Foundation
Status: substantially complete.

### Phase 1 — Launch Issue Architecture
Define total page count, number of features, page allocations, editorial rhythm, and story order.

### Phase 2 — Character 001
Build identity, narrative core, world rule, conflict engine, supporting cast, and first story.

### Phase 3 — Character 002
Independent character, ideally with a distinct genre and environment.

### Phase 4 — Character 003
Independent character, potentially more experimental.

### Phase 5 — Issue #001 Story Engineering
Premise → inciting change → escalation → reversal → crisis → climax → resolution → future hook.

### Phase 6 — Page Architecture
Page and panel design, page turns, reveals, dialogue, silence, visual storytelling, action, horror beats, and transitions.

### Phase 7 — Character & Environment Sheets
Front, side, rear, 3/4 views, expressions, costume details, scale, props, important locations, vehicles, technology, creatures, and AI consistency assets.

### Phase 8 — Comic Production
Cover → pages → lettering → effects → QA → continuity check → final issue.

### Phase 9 — Publish / Test
Evaluate character pull, premise strength, visual clarity, and expansion potential.

### Phase 10+ — Organic Expansion
Return features, new characters, first crossover, shared-universe revelations, teams, organizations, worlds, mythology, dimensions, and major events.
